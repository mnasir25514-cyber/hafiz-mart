# HAFIZ MART

HAFIZ MART is an online shopping website designed for a seamless grocery shopping experience. Users can select from a variety of grocery items, choose sizes, and receive their order receipts via WhatsApp. The website is built with a responsive design, ensuring accessibility on both desktop and mobile devices.

## Features

- **User-Friendly Interface**: Simple navigation and easy-to-use product selection.
- **Responsive Design**: Optimized for mobile and desktop viewing.
- **Product Selection**: Choose from 20 specific grocery items with size options.
- **WhatsApp Integration**: Receive order receipts directly via WhatsApp.

## Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd hafiz-mart
   ```
3. Install dependencies:
   ```
   npm install
   ```

## Usage

- Open `src/pages/index.html` in your browser to view the website.
- Select grocery items and sizes, then submit your order to receive a receipt via WhatsApp.
